# 2017年训练期育龄女性占比初始化诊断

## 问题与范围

基于提交`f461e82`开展本轮诊断。

在动态15—44岁女性分母和100条独立尺度轨迹条件下，只用2017年州级观测调整初始育龄女性占总人口比例，2021年GFR平均负偏差能下降多少？主指标是2021年平均偏差的绝对值；辅指标为MAE、RMSE、MAPE和逐州误差。

本轮匹配一个年龄—性别边际，即女性15—44岁占比。**这不等于完整年龄—性别结构校准**，更不等于年龄、婚姻、孩次和家庭结构的联合校准。

## 数据和信息边界

新增数据为官方[2017 ACS 1-year B01001 SEX BY AGE](https://api.census.gov/data/2017/acs/acs1/groups/B01001.html)，原始API响应保存为`data/observed/us_2021/acs_b01001_2017_initialization.json`，下载日期2026-10-25。原响应52行均保留，实验使用50州，排除DC和Puerto Rico。

目标占比为`sum(B01001_030E ... B01001_038E) / B01001_001E`。州级范围17.33%—21.82%，平均19.31%。来源、许可与转换方式登记在`data/observed/PROVENANCE.json`，数据SHA-256为`9d637bc1fc98e61f409d0e6d18f0d6cb072adbada22308b72c8f1bb51b988326`。

训练面板固定2010—2017；模型接口仅收到训练行和预测年份2018、2019、2021。没有下载新的测试期人口表，测试期人口字段不传入模型，已有测试期GFR仅供预测完成后评分。

ACS是居民调查估计，既有GFR分母来自PEP civilian系列，二者总体口径和版本不同。本实验直接使用ACS自身的同表分子与分母计算占比，没有把ACS总人口与PEP女性数混除。没有将ACS抽样误差或不同数据版本不确定性加入预测分布。

2018/2019/2021此前已被多次查看，本轮属于已检视历史诊断；2017 ACS是年度估计，不能视为2017年末实时可得的完整初始快照。

## 调整方法与固定设计

原始与调整版均使用1,200代理、20个目标seed（20261020—20261039）、每州100条独立尺度轨迹。沿用10月20日相同的预测、独立尺度seed和训练参数计算方式。调整同时用于预测世界和独立尺度世界。

先正常生成家庭，然后枚举整户整数年龄平移，按`绝对平移年数 × 成员数`的成本排序，贪心选择能缩小目标人数差异的操作。平移上限为30年，年龄限制0—110岁，原成年成员不能移到18岁以下。此排序是一种确定性的贪心近似，不保证全局最优。匹配目标为`round(1200 × 目标占比)`。

整户平移保留成员、亲子和伴侣关系、性别、亲子年龄差、教育、收入和既有孩次，不消耗随机数。平移后的年龄与教育、孩次等状态可能不完全协调；这个局限需要保留。相同seed并不保证调整后的事件抽样仍逐事件对齐。

实际6,000次初始化（50州×[100尺度+20目标]）全部匹配到目标整数人数，比例误差最大0.000414，符合最多半个代理的舍入误差。平均平移56.1人，占1,200人的4.7%；最多196人，实际最大平移11岁。

调整前平均育龄女性占比21.05%，调整后19.31%。总女性比例仍约50.05%，它没有被校准；其余年龄段及15—44岁内部年龄构成仍是合成的。不能据本结果声称全部年龄—性别结构已经接近真实值。

## 结果

未调整版的全部年份误差与10月20日归档值完全一致。

| 年份与指标 | 原动态分母版 | 2017占比调整版 |
|---|---:|---:|
| 2021平均偏差，GFR点 | −12.8372 | −11.8899 |
| 2021 MAE，GFR点 | 12.8372 | 11.9045 |
| 2021 RMSE，GFR点 | 13.2314 | 12.5139 |
| 2021 MAPE | 22.5254% | 20.6942% |
| 2018 MAPE | 4.6672% | 4.5770% |
| 2019 MAPE | 4.8951% | 5.2092% |
| 三年总体MAPE | 10.6959% | 10.1601% |

2021平均负偏差绝对值下降0.9473个GFR点，约7.4%。50州中27州绝对误差下降、23州未改善。2019年MAPE和RMSE均变差，这一结果完整保留。

按州配对bootstrap 2,000次，调整版减原版的2021平均偏差绝对值变化的95%百分位区间约为`[-2.0096, +0.1633]`；MAE变化区间约为`[-1.9806, +0.1687]`。两者均跨0。95.7%的重抽样有利于调整版，是条件于这些州、年份和模拟配置的重抽样比例，不能解释为假设为真的概率。

州bootstrap未覆盖全国共同冲击、独立尺度seed库的不确定性或ACS观测误差。不能将50州当成50个独立历史时期。当前证据仅支持小幅改善的点估计，不支持稳健改善的判断。

10月20日同一固定训练设计中，阻尼趋势代理的2021 MAPE为4.38%，仍远低于本轮调整版的20.69%；本轮没有重跑或调优该基线。

## 解释

训练期占比调整确实改变了后续出生和分母路径，且2021点估计方向有利；但仍有约92.6%的平均负偏差未被消除，2019还出现退化。单个初始占比不是剩余历史误差的主要完整解释。

这次结果不能排除更完整的年龄结构初始化问题：年龄别人数、年龄与伴侣状态、孩次、教育的联合分布仍未校准。它也不能证明出生规则本身错误；它表明现有规则与这一有限初始化改动合在一起，仍不足以复现真实2021动态。

当前生产默认值保持原样；训练期调整作为显式可选回调保留，完整`FamilyWorld`未改动。实验不支持因果政策主张。
