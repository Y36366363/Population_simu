# 独立尺度与同轨迹尺度比较

## 本轮问题

在机制、输入、初始规模不变时，当前用目标轨迹首年结果计算尺度的做法，和仅用独立训练轨迹估计尺度相比，哪一种能更准确、稳定地恢复已知生成过程中的观测映射？结果能否跨两个模拟年份保持？

本轮承接 2026-10-16 的归一化诊断，但不修改生产适配器、`World` 或 `FamilyWorld`。这里的“准确”只指恢复合成生成过程中的 oracle 映射，不是对现实出生率的预测准确性。

## 方法

固定以下条件：训练末值 GFR=60、`initial_people=1200`、住房弹性为−1、目标年份为2018和2019。住房负担取0.20、0.35、0.50。住房仍同时进入既有的 `fertility_multiplier` 和 `childcare_support`，因此不能把差异解释为单一住房通道。

使用三个互不重叠的 seed 集合：

- 800条 reference-burden 轨迹估计 DGP 首年原始率的总体均值，形成有限 Monte Carlo oracle 尺度；
- 120个 target seed × 3种负担用于评估；
- 50个独立校准重复，分别用1、5、20和100条训练轨迹估计尺度。

oracle 尺度定义为 `60 / oracle首年原始率均值`。同轨迹尺度为每条目标轨迹自己的 `60 / R1`；独立尺度只用独立的 reference-burden 训练轨迹计算，然后应用到全部目标轨迹。评估两项：

1. 相对于 oracle 映射的 bias、MAE 与 RMSE；
2. 高住房负担减低住房负担的配对机制对比能否被保留。

实际命令：

```bash
python scripts/compare_scaling_estimators.py \
  --output docs/artifacts/scaling_estimator_comparison_2026-10-17.json
```

命令退出码为0，耗时约40秒。所有逐 seed 原始结果、尺度估计、设计、限制和源文件 SHA-256 均保存在 JSON 中。

## 结果

800条 oracle 轨迹的首年原始率均值为25.8833，Monte Carlo 标准误为0.2317，对应尺度2.3181。前后各400条轨迹得到的尺度分别为2.3415与2.2952，说明 oracle 本身仍有约2%的有限模拟差异，不能当作解析真值。

### 观测映射误差

| 方法 | 训练轨迹数 | 尺度标准差 | 2018 RMSE | 2019 RMSE |
|---|---:|---:|---:|---:|
| 同轨迹首步 | 每个目标自身 | 不适用 | 17.4925 | 19.8649 |
| 独立尺度 | 1 | 0.5757 | 9.9359（中位数） | 8.8036（中位数） |
| 独立尺度 | 5 | 0.2446 | 3.9810（中位数） | 3.5274（中位数） |
| 独立尺度 | 20 | 0.1335 | 2.7988（中位数） | 2.4799（中位数） |
| 独立尺度 | 100 | 0.0584 | 1.3591（中位数） | 1.2042（中位数） |

独立尺度的方差和映射误差随训练轨迹增加明显下降，且这种改善在两个年份均存在。100条训练轨迹的平均尺度为2.2940，相对有限 oracle 的偏差为−1.04%；其50次重复的尺度2.5%—97.5%经验范围为2.1911—2.4000，包含 oracle 尺度。

同轨迹方法在2018年把全部输出强制为60，因此若只以“离60多近”为标准会显得完美；但对每条随机轨迹的 oracle 映射，它的2018年RMSE为17.4925。这两种说法对应不同 estimand，不能混用。

### 住房负担对比

oracle 映射下，高负担减低负担的平均差为2018年−22.4404、2019年−19.9936。这里是合成模型内部响应，不是真实住房效应。

- 同轨迹尺度将2018年的差异严格压成0，对比误差RMSE为26.2248；2019年平均差变成+2.9434，对比误差RMSE为30.6008。
- 使用100条独立训练轨迹时，对比误差RMSE的50次重复中位数为2018年0.5737、2019年0.5375；97.5%经验分位数分别为1.4365与1.3459。

因此，同轨迹尺度不仅引入随机分母，还可能改变机制对比的方向。独立尺度在这个已知DGP中明显更能保留既有响应。

## 如何判断“持续准确”

当前证据支持一个有限结论：在固定的合成DGP、1200代理和两个年份内，独立尺度随着独立训练轨迹增加而稳定接近 oracle 映射，并保留住房对比；同轨迹尺度没有做到这一点。

当前证据不支持以下结论：

- 独立尺度已经能准确预测现实州级GFR；
- 100条轨迹是普遍充分的阈值；
- 两年表现能外推到十年或更长；
- 完整 `FamilyWorld` 已得到经验验证；
- 合成住房差异是因果效应。

原始率仍以初始人口×0.5近似分母，而非真实15—44岁女性暴露。当前 experiment 只隔离了尺度估计误差，没有检验结构误差、参数误差或随机实现的真实可预测性。

## 建议由用户决定的下一步

如果继续沿证据诊断推进，下一步最有区分力的问题不是立即替换生产尺度，而是固定100条独立校准轨迹，检查初始规模（例如1200与更大规模）和预测长度是否改变尺度方差、机制对比和误差增长。若误差随规模增大下降，主要问题偏向 Monte Carlo 噪声；若长期系统漂移仍存在，则更可能是动态结构或观测映射问题。

在这个检查前，不应把本轮结果写成新的现实预测结论。
