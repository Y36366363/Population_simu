# 动态育龄暴露候选的历史诊断

## 术语与问题

**DGP（data-generating process，数据生成过程）**是产生数据的规则。此前合成实验把`World`本身当作已知DGP，因此可以判断观测映射能否恢复这个已知过程，但不能据此断言现实世界也遵循相同规则。

**held-out GFR**是校准时不读取、预测后才用于评价的历史一般生育率。GFR是每1,000名15—44岁女性对应的出生数；项目中的旧列名`asfr_15_44`实际是GFR，而不是年龄别生育率。

本轮问题是：合成DGP中有效的动态女性15—44岁分母，接入可切换候选接口后，能否改善美国州级历史GFR预测？

## 接口与信息边界

`household_simulator_runner()`新增两个显式、非默认参数：

- `exposure_denominator="dynamic_female_15_44"`：每个预测年使用模拟内部女性15—44岁人数；
- `independent_scale_paths=100`：使用与目标轨迹不同的100条模拟轨迹估计尺度。

旧默认仍为同轨迹首步尺度和`initial_people × 0.5`分母，已有调用行为保持不变。

真实面板中的`female_15_44`只用于构造观测GFR和预测完成后的相关性诊断。模型没有读取2018、2019或2021真实女性分母，也没有读取未来住房值。动态候选使用的是模拟器自身生成的年龄—性别结构。

## 评价设计

- 面板：美国50州，2010—2019和2021；
- 固定训练期：2010—2017；
- 评价年份：2018、2019、2021，对应1、2、4年跨度；
- 20个Monte Carlo预测重复；
- 每州100条独立尺度轨迹；
- 2,000次州级聚类bootstrap，保留每州三个年份；
- 比较简单趋势、阻尼趋势代理、reduced form、旧household、固定分母独立尺度、动态分母独立尺度。

这些历史结果此前已经被查看过，所以本轮是**已检视历史诊断**，不能重新称作新鲜untouched test。阻尼趋势代理也不是真正cohort-component模型。

命令：

```bash
python scripts/evaluate_dynamic_exposure_holdout.py \
  --panel data/observed/us_2021/us_research_panel_2010_2021_comparable.csv \
  --output docs/artifacts/dynamic_exposure_historical_diagnostic_2026-10-20.json \
  --replicates 20 --scale-paths 100 --bootstrap-draws 2000
```

## 总体结果

| 模型 | MAPE | RMSE | 预测变化与真实变化相关系数 |
|---|---:|---:|---:|
| naive trend | 3.073% | 2.988 | 0.780 |
| damped trend proxy | 2.762% | 2.030 | 0.701 |
| reduced form | 3.405% | 2.903 | 0.752 |
| household：旧同轨迹＋固定分母 | 10.935% | 8.513 | 0.650 |
| household：独立尺度＋固定分母 | 11.768% | 9.232 | 0.636 |
| household：独立尺度＋动态暴露 | 10.696% | 8.161 | 0.616 |

动态候选相对旧household的MAPE仅下降约0.24个百分点。州聚类bootstrap的差值区间为−0.94至+0.48个百分点，跨过0；没有足够证据说候选整体优于旧实现。

但是在相同的100条独立尺度设计下，动态分母比固定分母低1.07个百分点，州聚类bootstrap区间为−1.43至−0.74，所有2,000次重抽样均有利于动态分母。这说明动态分母本身在这组历史年份确实修复了一部分误差。

独立尺度＋固定分母反而比旧同轨迹锚定更差，说明旧方法的首年强制锚定能在短期历史评分中掩盖尺度不确定性。合成DGP中独立尺度更忠实于已知映射，不等于它会自动提高现实预测。

## 分年份结果

### MAPE

| household版本 | 2018 | 2019 | 2021 |
|---|---:|---:|---:|
| 旧同轨迹＋固定分母 | 2.142% | 8.357% | 22.306% |
| 独立尺度＋固定分母 | 4.612% | 4.258% | 26.435% |
| 独立尺度＋动态暴露 | 4.667% | 4.895% | 22.525% |

动态候选改善了固定独立版本在2021年的严重低估，但没有恢复到简单基线水平。它在2018、2019也没有一致领先旧household。2021仍有约−12.84个GFR点的平均偏差，因此现实失配的主要部分不是分母选择能够解释的。

## 历史趋势关联

动态候选的预测水平与观测水平相关系数为0.695，高于旧household的0.536；但相对2017年的变化相关系数由0.650降到0.616，仍低于naive trend的0.780。

预测误差与真实女性15—44岁暴露增长的相关系数：

- 旧household：−0.403；
- 固定分母独立尺度：−0.438；
- 动态候选：−0.402。

动态候选没有消除这种描述性关联。原因可能是模拟内部年龄结构没有匹配各州真实年龄结构，或者出生动态本身存在结构失配。相关系数不是因果证据，也不能用来把未来真实暴露直接输入事前预测。

## CRPS与区间

动态候选CRPS为4.95，略差于旧household的4.78；覆盖率从0.667升到0.973，但区间平均宽度也从28.38升到31.14。高覆盖主要来自非常宽的Monte Carlo区间，不能解释成更准确或更可信。阻尼趋势代理点预测更好，但本轮没有为确定性基线添加预测误差层，因此其零宽区间和零覆盖不适合作为区间性能比较。

## 判断

本轮支持以下结论：

1. 动态育龄分母是正确且低成本的候选接口；在相同独立尺度下，它对历史预测有可测的改善。
2. 合成DGP中的巨大改善没有转化成现实历史数据中的同等改善。
3. household模型仍显著落后于简单基线；分母修复不是主要失配的完整答案。
4. 真实人口结构值得接入，但下一问题不应是把测试期真实分母直接喂给模型，而是校准模拟初始年龄—性别结构并预测其演化。

生产默认值暂不替换。若直接改默认，可能改善内部一致性，却会在缺乏外部年龄结构校准时制造“已验证”的错误印象。

## 局限与下一决策

- 只有三个已检视年份，不是新的独立历史证据；
- household适配器使用简化`World`，不是完整`FamilyWorld`；
- 动态暴露由模拟内部生成，尚未匹配各州2017年真实年龄—性别结构；
- 住房、年龄结构与生育变化的相关性不能解释为因果关系；
- 本轮候选仍使用1,200代理，100条尺度轨迹不消除结构误差。

下一步最有区分力的问题是：只替换模拟的初始年龄—性别构成，使其匹配训练期各州已知女性15—44岁占比，同时不读取测试期分母，检查2021长期偏差是否下降。若下降，说明人口结构初始化是剩余问题的重要部分；若不下降，应转向出生机制和状态映射，而不是继续提高代理数量。
