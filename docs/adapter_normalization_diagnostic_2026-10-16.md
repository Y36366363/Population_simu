# 首次研究诊断：适配器的归一化与机制响应

## 范围与版本

基于 `7ad9068`，只增加独立诊断脚本与结果，未修改 World、FamilyWorld 或预测适配器。此后每次更新应报告研究问题、方法、结果、解释与局限，交由用户决定下一步。此前两周和后续时间计划暂不执行。

## 问题与事前设计

首步模拟出生率既用于确定缩放系数，又作为被缩放的输出，是否使一年期机制响应抵消？另外检查 no-household 是否等同趋势基线，以及命名的年龄/孩次先验是否实际影响 adapter。

固定合成训练 GFR 为2016年62、2017年60，目标2018和2019；住房负担0.20、0.35、0.50，seed 0—19，1200代理，住房弹性人为固定为−1。不读取历史测试结果，不加残差噪声，不提供 future_housing。每组另将 age_profile 与 parity_progression 联合改为0.1，检查输出。设计在运行前写入脚本。

这里60组是60个 seed×住房配置；每组还执行先验扰动对照。其模拟不确定性不能代表现实人口参数不确定性。住房同时改变乘子和托育支持，所以不能将响应解释为纯住房作用。

## 实际运行

命令：

```bash
python scripts/diagnose_adapter_normalization.py --output docs/artifacts/adapter_normalization_diagnostic_2026-10-16.json
```

退出码0；来源SHA与逐组结果保存在该JSON。结果为：

- 60组首年出生数均非零；缩放首年与60的最大差为7.11e−15。
- 20个seed中19个在高/低负担之间有原始首年响应；高减低的原始比率均值为−9.1667。该比率仍使用初始人口×0.5作分母，不能称为真实ASFR。
- 缩放首年高减低差的最大绝对值为7.11e−15，响应被抵消。
- 二年期输出与 `60 × 原始第二年比率 / 原始第一年比率` 最大差1.42e−14。
- 所有组的 no-household 与最近两点趋势在残差噪声前完全一致。
- 联合改变年龄和孩次先验后所有输出完全一致。当前 adapter 没有将这两个字段传入 World；World 仍有自身硬编码年龄和孩次规则，不能据此说这些机制不存在。

另运行一个低成本边界断言：用 `unittest.mock.patch` 替换 `World.run`，令2018/2019出生数为0/12，调用同一 adapter，确认缩放输出为0/20，退出码0。这是构造的边界测试，不是观察到的模拟结果：首年零出生时 scale=1，首年锚定性质不适用。

未重跑完整回归、网页测试或历史评估；生产引擎没有变化。本轮没有得到新的预测精度分数。

## 解释与下一步候选

设训练末年GFR为G，首年和第二年原始比率为R1、R2。首年非零时，scale=G/R1，所以首年输出=G，第二年输出=G×R2/R1。这说明当前一年期输出无法据此检验既有机制响应，而二年期包含随机分母。随机分母解释多少历史误差尚未验证。

no-household 在当前定义下是趋势模型的别名；加噪后的微小分数差异不能归为家庭机制贡献。命名参数存在不等于实际接入。本轮既不证明家庭机制无效，也不提高完整FamilyWorld的经验有效性。

建议下一次由用户选择是否研究随机分母：固定机制、输入与规模，比较同一次轨迹首步尺度和独立训练期估计尺度，先检查已知生成过程下的偏差与方差。另一个候选是先完成年龄/孩次参数的调用链清单；不应直接将未识别参数接入后宣称已校准。暂不改变生产归一化规则，也不开始长期实验网格。
