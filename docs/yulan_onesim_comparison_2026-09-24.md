# YuLan-OneSim 对本项目的借鉴边界 · 2026-09-24

## 结论

YuLan-OneSim 的价值主要在于“如何组织和复现模拟实验”，而不是把
大模型自主行为直接放进当前人口模型。它展示了自然语言场景配置、可演化
的模拟流程、事件/记忆追踪、批量运行和理论—现实双重验证等工程模式。
这些模式可以增强本项目的可审计性和网页回放，但不能替代当前冻结的
美国州—年历史检验。

项目说明见 [YuLan-OneSim README](https://github.com/RUC-GSAI/YuLan-OneSim)。

## 可以立即采用的部分

1. **场景契约**：每次运行都由一个版本化 JSON 明确 outcome、exposure、
   calibration/test 年份、模型集合、随机种子和 artifact 引用。网页只读取
   通过验证的契约和结果，不从自由文本临时拼装参数。
2. **可追踪事件**：本地家庭模拟可以输出年度决策摘要（家庭状态、住房负担、
   资源、迁移结果和随机种子），用于解释和回放；这不是新增社会机制。
3. **双重验证门**：保留理论性质检查（例如固定随机种子下的单调性）和真实
   州—年历史 holdout 检查（RMSE、MAPE、CRPS、coverage）。两者分开报告。
4. **批量可复现**：同一场景可用共同随机数运行 full/no-housing/no-household，
   保存中位数和区间，并生成网页时间线或 PNG 帧。

## 暂不采用的部分

- 用 LLM 临时决定生育、婚姻或迁移：会改变 estimand，且难以识别参数；
  在真实分层出生分子和暴露分母完成前不应加入。
- 自动“自我进化”的 agent 规则：会破坏 feature freeze 和 untouched test。
- 100k agent 的分布式基础设施：当前问题是 50 州年度预测和机制解释，
  规模不是瓶颈。
- 以自然语言生成配置作为唯一入口：可作为未来网页辅助层，但最终必须落到
  下面的类型化场景契约并经过校验。

## 当前应用

`data/fixtures/frozen_study_scenario.json` 是第一个可复现的场景契约。它
锁定住房主规格、2010–2017 calibration、2018/2019/2021 untouched test、
四类预测/机制模型和现有数据闸门。它不解锁托育或年龄—婚姻—孩次 hazard，
也不宣称因果识别。

后续网页可将该契约作为“保存/复现情景”的唯一入口；当正式历史回放完成后，
再把验证过的 artifact 列入 `artifact_refs`，而不是修改历史结果。
