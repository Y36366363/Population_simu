# 通用实验地区人口流量审计 · 2026-10-03

本轮沿用 `experiment_architecture_2026-10-02.md` 的建设顺序，不增加国家、政策、职业、UI或社会机制。目标是把已有“全球人口出生—死亡闭合”推进到可解释的地区人口流量闭合。

## 实现

`FamilyWorld`在每个年度过程前后观察在世个人的国家—地区位置，并保存：

- 出生和死亡；
- 专门国内迁移的迁入与迁出；
- 国际迁移的迁入与迁出；
- 婚配与离婚造成的搬家；
- 不能归入既有过程的`other_in`与`other_out`。

每个地区必须满足：

`closing = opening + births - deaths + inflows - outflows`

通用实验运行器把该账本写入每个分支的年度审计；任一地区不闭合或缺少账本时立即拒绝实验结果。账本只观察现有过程，不调用随机数，也不改变模拟轨迹。

## 真实回归结果

重新运行 `experiments/general_controls.json`，共3个seed、baseline加7个实验组、3个干预后年度：

| 检查 | 结果 |
|---|---:|
| 年度分支审计 | 72 |
| 地区—年度账本行 | 720 |
| 不闭合地区行 | 0 |
| 未分类迁入 | 0 |
| 未分类迁出 | 0 |
| 记录出生 | 4,522 |
| 记录死亡 | 368 |
| 国内迁入 | 4,936 |
| 国际迁入 | 536 |
| 婚配搬家迁入 | 196 |

流量总数是架构回归样本，不是现实人口估计。迁入和迁出在世界内部成对出现；国际迁移在本模型国家集合之间发生，因此不会改变世界总人口。

## 边界与下一步

当前账本按年度过程阶段聚合，可以回答“哪一类现有过程造成了地区人口变化”，但不能冻结分支间共享事件，也没有事件日期、序号和稳定随机键。下一步仍应优先实现事件寻址随机数与外生路径提供器；之后再把人口账本扩展为资源/现金双边转移账本和双系谱系查询。不能把本轮闭合检查解释为真实数据校准或政策因果识别。
