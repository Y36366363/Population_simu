# 家族沙盘 v2：当前假设与待校准项

## 研究问题

当前版本把用户提出的问题拆成三个不能互相替代的指标：

1. **单个孩子成功率**：资源集中是否提高一个随机孩子的教育/阶层结果？
2. **家庭至少一人跃迁率**：多生是否通过增加独立尝试次数，提高一家出现一个“爆发孩子”的概率？
3. **家族长期存续与总体负担**：少生带来的资源集中，是否以家族分支减少、老龄化或劳动力收缩为代价？

因此，“一孩最好”“两孩最好”不能先写入模型结论，而要由目标函数、参数和不确定性共同决定。

## 当前因果链

```text
国家发展/城市化/养育成本
        ↓
家庭生育意愿 ← 家庭财富（贫困加成 + 中产抑制 + 富裕回升）
        ↓
实际子女数 ← 政策上限与执行强度
        ↓
金融/住房/时间资本按不同速度被子女数量摊薄
        ↓
每孩九维资本 + 先天潜力 + 父母职业/阶层 + 国家制度 + 运气
        ↓
成年职业与经济地位 → 是否越过成家繁衍死线 → 下一代生育与投入
```

## 当前简化

- “姓氏家族”只是追踪分支与代际结果的标签，不代表共同能力或固定遗传品质。
- 每个姓氏初始只有一个家庭，因此 300 个姓氏是 300 个模拟创始家族，不等于真实姓氏人口分布。
- 目前默认父系姓氏继承；跨姓婚姻中双方仍保留出生家族身份。
- 目前只实现男女配对和共同生育，尚未覆盖收养、单亲、同性伴侣、辅助生殖与不婚生育。
- 家庭内部暂时平均分配教育预算，没有长幼、性别偏好、健康差异或“重点培养某一个孩子”。
- “成功”暂以经济地位达到阈值表示，尚未加入幸福、健康、照护贡献、科研文化成就或风险偏好。
- 国家数据均为缩放后的机制参数，模拟人口不是现实人口数量。

## 九维资本

| 资本 | 当前作用 | 子女增多时 |
|---|---|---|
| 金融资产 | 教育投入、住房、成家启动金 | 接近按人数摊薄 |
| 人力资本 | 学习环境、职业准入 | 中度传递 |
| 社会资本 | 推荐、信息与关系网络 | 较慢摊薄 |
| 政治资本 | 公共权力职业入口 | 传递强，但受制度开放度抑制 |
| 文化资本 | 学习习惯、表达与职业认知 | 中度摊薄 |
| 住房资本 | 成家门槛 | 快速摊薄 |
| 健康资本 | 劳动能力和死亡风险 | 缓慢传递 |
| 照护时间 | 每孩陪伴与教育 | 快速摊薄 |
| 债务 | 消耗现金并抬高风险 | 多孩和高房价可能累积 |

## 职业继承

职业不是固定继承。模型通过四条渠道提高父子/母子职业相似概率：专业知识、人力资本、社会关系和职业准入门槛。制度开放度越高，能力权重越大，关系继承权重越低。高风险不稳定劳动的代际延续同样是概率性的“黏性底层”，不是给家庭或个人贴永久标签。

OECD 的跨国研究认为，父母教育、收入和职业与子代结果存在显著的代际持续性；即使控制子代自身教育，部分国家仍存在父母背景影响。职业相关性可能来自专业知识、教育分层、准入壁垒和家庭网络。因此模型没有把职业同类继承解释为先天决定。

- OECD 代际流动综述：https://www.oecd.org/en/publications/intergenerational-social-mobility-across-oecd-countries_6d76ec2a-en.html
- OECD 职业流动与传递渠道：https://www.oecd.org/en/publications/catching-up-intergenerational-mobility-and-children-of-immigrants_9789264288041-en/full-report/component-6.html
- 世界银行全球代际流动数据库：https://www.worldbank.org/en/topic/poverty/brief/what-is-the-global-database-on-intergenerational-mobility-gdim

## 动态死线

“死线”只表示在给定制度下稳定成家和生育的资源承载阈值，不表示人的价值。它是软概率曲线：低于阈值后概率快速下降，但不会归零。阈值随住房压力、养育成本和发展水平上升，随福利托底和育儿支持下降。

多代实验必须做阈值敏感性分析。若住房昂贵、福利弱，100资源集中给一人可能比拆给三人更容易延续；若公共教育、住房和托育覆盖较好，多孩的“多次尝试”优势可能重新出现。前者不是预设为普遍规律。

## v4 动态家庭与空间机制

- 经济周期是正弦周期与随机负向冲击的组合；衰退提高失业、债务、离婚和返乡倾向，繁荣提高工资和再就业。
- 离婚会分割现金和住房资本，产生新家庭分支，并按概率决定子女监护；离婚者可进入再婚池。
- 性别差异通过劳动参与、工资差距、母职职业中断和子女投资偏好实现，所有参数都可设为零以运行性别中性反事实。
- 地区具有城市/乡村属性、工资、住房、学校和就业机会；迁移由这些收益和家庭资源脆弱性共同决定。
- 制度开关实验遵守“一次只改变一个制度”的规则，避免把公共教育、住房供给、反裙带和福利托底混成单一政策包。

## v5 健康、养老与家庭照护

- 慢性病按年龄、既有健康资本与国家基础发病率随机发生，并可能逐年发展为失能；它不是由阶层或职业直接决定的固定标签。
- 医疗可及性降低健康恶化和家庭自付支出。年度医疗支出超过家庭永久收入的 20% 时，记为模型中的“灾难性医疗支出”，并增加债务。
- 老年、慢性病和失能形成家庭照护需求；公共长期照护降低家庭承担部分，剩余负担消耗照护时间，并对女性劳动收入施加更大的默认影响。该性别差异参数未来可单独拆出。
- 退休成员按永久收入与养老金替代率取得简化养老金。这一版尚未建立缴费池，所以不能用于判断养老金财政是否可持续。

## v6 托育、祖辈照护与动态投资

- 正式托育覆盖由国家供给容量、补贴、地区就业条件和多子女需求共同决定；家庭仍承担一部分费用，托育为学龄前儿童增加公共早期投入。
- 祖辈照护必须沿真实父母—祖父母关系寻找。贡献随异地居住、健康下降、失能和未退休而减少，同时消耗祖辈家庭的照护时间，避免把祖辈劳动视作免费资源。
- 动态投资只使用家庭已经观察到的健康、教育和人力资本信号，不直接读取模型中的“先天潜力”。追投权重提高时，资源向当前表现较强者倾斜；弱势补偿权重提高时，部分资源回流健康或表现较弱者。
- 兄弟姐妹投资集中度用年度投入份额的 HHI 表示。该指标只衡量分配是否集中，不判断集中本身是否公平或有效。
- 网页端为了即时交互使用轻量多代 Monte Carlo 近似；完整年度模型仍以 Python 引擎结果为准。两者只能比较机制方向，不能混合解释绝对数值。

## 网页世界沙盘的主次关系

- 世界沙盘以家庭为最小代理：家庭持有地区、资源、人力资本、成年成员年龄、未成年子女、代际编号和姓氏家族编号。
- 成年子女会建立新的家庭分支；家庭根据不同地区的工资、学校、住房和福利效用决定是否迁徙。沙盘汇总家庭数量、跨区域流量、资源中位数、子女数和高状态家庭占比。
- 当前世界区域是六个关系示意区域，位置不是地理比例地图，参数也不是六个真实大洲的统计估计。
- 一孩、二孩、三孩资源配置属于独立子实验，用于研究家庭内部权衡；其结果不会被当作世界沙盘的唯一人口机制。

## v7 可校准人口学接口

- 生育、死亡和迁移都可以通过年龄率表覆盖默认函数；缺少率表时才使用透明的示意曲线。
- 内部迁移支持地区—地区矩阵，并通过 softmax/logit 权重抽样，避免所有家庭机械地选择最高效用地区。
- 同一区域其他家庭的平均已生子女数以 `social_norm_strength` 影响生育意愿，作为社会规范的最小机制。
- `family_monte_carlo` 使用共同随机数比较情景，输出均值、中位数和区间；历史回放使用 MAE、RMSE、偏差和 MAPE。

## v8 地区宜居度与非线性压力

- 每个地区新增 `amenity_supply`（0—1），代表教育、托育、公共空间和基础服务的综合供给，不等同于家庭财富。
- 地区迁移效用会给公共服务供给一个小权重；因此迁移不再只追逐工资最高的地区。
- 生育意愿对宜居度缺口施加软惩罚，并在家庭已有照护缺口时放大；它不会把低服务地区设成“绝对不能生育”。
- 该机制借鉴《文明》系列 housing/amenities 的可读性，但没有把游戏中的离散惩罚直接当作现实规律。真实校准应拆分学校、托育、医疗、交通和安全，并使用地区面板数据估计阈值。

## v9 地区财政、承载力与技术反馈

- `Region` 现在可分别设置学校、托育、医疗、交通和安全供给；`service_index` 是兼容旧版综合 amenity 的加权汇总，不代表单一幸福指数。
- 地区承载力由初始家庭规模、服务供给、就业机会、住房成本和 `carrying_capacity_scale` 共同决定。压力超过 1 后，会降低迁移效用和生育意愿；这是软拥挤效应，不是硬人口上限。
- 国家财政用税收减去教育、医疗和养老支出形成年度简化余额。它用于政策反事实和压力展示，尚未建立真实税制、缴费池或跨地区转移支付。
- 技术指数按 `technology_growth` 累积；自动化提高技术部门收入、压低常规/不稳定劳动收入，并小幅提高结构性失业压力。当前仍是透明的机制占位，不是生产函数估计。
- 承载力扫描使用年度缓存，避免在每次迁移选择时重复扫描全部人口；缓存只影响计算性能，不改变随机抽样规则。

## v10 社会规范来源

- `social_norm_sources` 将生育规范拆为邻居、亲属、同事和媒体四类来源；权重可在国家层面调整。
- 邻居使用同地区家庭，亲属使用同姓氏家族分支，同事使用同地区且有相同成年职业的家庭，媒体使用国家基线规范。
- 当前仍是低阶网络近似：没有显式社交图、信息扩散或同质性选择。下一步应使用调查或网络数据估计各类来源的相关性，避免把四个来源误当成独立信息。

## v11 环境冲击模块

- `EnvironmentalProcess` 使用独立于家庭/经济周期的随机流；同一 seed、年份、国家和地区会得到相同事件。
- 灾害类型目前为干旱、洪水和高温三类占位事件。事件通过概率、强度和恢复年限形成地区环境压力。
- 环境压力降低劳动收入、提高死亡风险、降低迁移效用，并增加公共环境支出；资源约束会进一步压低收入。
- `environment-sensitivity` 只改变灾害概率，使用共同随机数输出人口、环境压力、气候事件数和财政结余的中位数及区间。
- 地区可分别设置历史灾害频率、人口暴露度和恢复成本；敏感性分析可通过 `--factor` 一次只改变其中一个因素。
- 当前不模拟战争；气候事件也没有被解释为现实预测。真实化需要灾害历史、暴露人口、地区资源和恢复成本数据。

## v12 理论结构与审计

- 项目采用“家庭 ABM + cohort-component 宏观审计 + 系统动力学反馈”的混合路线。
- `FamilyWorld.audit()` 检查国家—地区人口/家庭分区、非负性和关键年度指标，不能替代真实数据校准。
- 理论对照和优先级见 `docs/theory_comparison.md`；新增机制必须同时提供极端情景、敏感性和共同随机数测试。

## v13 人口矩阵、基金与校准

- `FamilyWorld.age_sex_matrix()` 按国家、性别和单岁年龄汇总家庭明细；`snapshot()` 暴露该矩阵，审计层检查其合计等于国家人口。
- 政府基金余额按年度累积国家收支；地区收支不平衡通过显式转移支付指标记录，转移不改变国家总余额。
- 婚姻、生育、离婚和迁移先计算 hazard，再转换为一年内事件概率；家庭分支保存出生和迁移间隔，减少“每年独立抽签”的假设。
- `RegionMigrationNetwork` 只处理地区可达性和矩阵边权，`FamilySocialNetwork` 只处理亲属、邻居和同事关系，二者不共享决策状态。
- `calibration.replay_errors()` 按年份对齐观测与模拟，输出 MAE、RMSE、Bias、MAPE；它是校准入口，不是自动优化器。

## v14 真实观测快照与参数搜索

- `data/observed/owid_demography_sample.csv` 固定保存中国、印度、日本和美国
  1950—2023 年的 OWID/UN WPP 人口、粗出生率、粗死亡率和总和生育率；出生、
  死亡数量由人口与粗率推导，不能与独立登记数据重复加权。
- `replay_errors_by_group()` 按 `entity`（或其他分组列）分别对齐年度，避免
  多国数据在同一年份被字典覆盖；`grid_search()` 与 `random_search()` 复用
  同一个 `simulate(parameters)` 契约，后者固定 seed 后可复现。
- 搜索结果是拟合优度，不等于因果识别。正式研究应先留出验证年份，报告参数
  不确定性和跨国异质性，再把校准后的参数用于共同随机数政策反事实。

## v15 时间外推验证

- `temporal_split()` 按实体分别保留末段年份作为验证期，避免把未来观测泄漏到
  参数搜索；默认至少保留三个训练年份。
- `evaluate_parameters()` 对搜索得到的参数生成独立验证报告。若训练目标很低而
  验证目标明显升高，应优先减少参数自由度或增加分层数据，而不是继续堆叠机制。
- CSV 加载现在要求 `year` 列并拒绝非有限数值；网格为空、随机边界反转等输入
  会立即报错，减少静默地产生不可解释的校准结果。

## v16 横向验证与概率区间

- `rolling_origin_splits()` 用 expanding-window 方式做滚动回测；人口序列不能
  随机打乱，否则会把未来年龄结构和政策信息泄漏到过去。
- `leave_one_group_out()` 用其他国家/地区拟合，再评估被留出的实体，用于检查
  参数是否只适用于某一个国家。它不是“跨国普适性”的证明，只是一个压力测试。
- `interval_metrics()` 报告 Monte Carlo 区间覆盖率与平均宽度，分别对应校准性
  和 sharpness。概率预测研究通常建议同时报告两者，而不能只看点预测 MAE；
  这与概率预测和人口预测文献中的 proper scoring / calibration-sharpness 思路一致。

## v17 概率评分与模型基准

- `empirical_crps()` 使用样本形式的 CRPS：
  `平均|样本-观测| - 0.5×平均|样本-样本'|`。它对概率分布是 proper score，
  对单点预测退化为绝对误差，因此可以公平比较确定性基准和 Monte Carlo 模型。
- `stratified_interval_metrics()` 按实体或其他字段分层输出覆盖率，防止大国的
  年份数量掩盖小国、低生育国家或特定政策阶段的失配。
- `benchmarks.compare_models()` 在同一训练/预测窗口内比较多个 runner。固定趋势
  基准用于检验模型是否至少胜过朴素外推；`wpp_style_runner` 只是阻尼趋势占位，
  不是 UN WPP 实现。接入真实年龄—性别 cohort-component runner 后无需改评估层。
- 交叉验证报告应同时包含点误差、CRPS、覆盖率和区间宽度；单独追求最低 MAE
  可能选择过度自信的模型，单独追求覆盖率又可能选择极宽、没有信息量的区间。

## v18 多窗口置信度与配对比较

- `compare_models_rolling()` 使用 expanding-window 折叠，而不是依赖一个任意的
  训练/测试切点；每折对各实体先算 MAPE/RMSE，再跨实体平均，降低人口规模差异
  对横向比较的支配作用。
- 每个折叠的模型使用相同的随机种子序列（common random numbers），并将模型与
  同一朴素基准的逐折误差差值做 bootstrap。输出包含均值、95% 区间和胜率，避免
  把一次随机模拟或单个历史阶段的优势误读为普遍规律。
- “置信度增强”在这里指预测误差和不确定性的统计诊断，不是因果识别置信区间。
  若滚动窗口之间方向不一致、区间跨越零或覆盖率明显偏离名义水平，应把结论
  标为探索性，并继续校准年龄结构、迁移矩阵和政策实施时点。

| 1980—2015 | 独生子女为主（含例外） | 上限 1、执行强度 0.88 |
| 2016—2020 | 全面两孩 | 上限 2、执行强度 0.55 |
| 2021— | 三孩及配套支持 | 上限 3、低限制、托育支持增加 |

执行强度是人为设定的实验参数。真实版本必须按城乡、民族、地区和年代分别校准，不能把全国长期视为完全一致的硬性一孩制度。

## 下一轮最有价值的条件

1. 家庭资源的真实含义：年收入、净资产、可用于教育的现金，还是社会关系资本。
2. “成功”的目标：进入收入前 10%、大学毕业、跨阶层、还是家族总财富增长。
3. 子女结果相关性：同胞共享基因、学校、地区冲击，因此并非完全独立的彩票。
4. 家庭策略：平均分配、优先长子、优先最有潜力者，或观察成绩后动态追加。
5. 国家制度：税收、免费教育、住房、养老金与医疗会改变“多一个孩子”的边际成本。
6. 人口反馈：劳动力短缺推高工资、老龄化提高税负、技术进步替代劳动。
