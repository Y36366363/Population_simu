# 家族沙盘 v2：当前假设与待校准项

## 研究问题

当前版本把用户提出的问题拆成三个不能互相替代的指标：

1. **单个孩子成功率**：资源集中是否提高一个随机孩子的教育/阶层结果？
2. **家庭至少一人跃迁率**：多生是否通过增加独立尝试次数，提高一家出现一个“爆发孩子”的概率？
3. **家族长期存续与总体负担**：少生带来的资源集中，是否以家族分支减少、老龄化或劳动力收缩为代价？

因此，“一孩最好”“两孩最好”不能先写入模型结论，而要由目标函数、参数和不确定性共同决定。

## 当前因果链

```text
国家发展/城市化/养育成本
        ↓
家庭生育意愿 ← 家庭财富（贫困加成 + 中产抑制 + 富裕回升）
        ↓
实际子女数 ← 政策上限与执行强度
        ↓
金融/住房/时间资本按不同速度被子女数量摊薄
        ↓
每孩九维资本 + 先天潜力 + 父母职业/阶层 + 国家制度 + 运气
        ↓
成年职业与经济地位 → 是否越过成家繁衍死线 → 下一代生育与投入
```

## 当前简化

- “姓氏家族”只是追踪分支与代际结果的标签，不代表共同能力或固定遗传品质。
- 每个姓氏初始只有一个家庭，因此 300 个姓氏是 300 个模拟创始家族，不等于真实姓氏人口分布。
- 目前默认父系姓氏继承；跨姓婚姻中双方仍保留出生家族身份。
- 目前只实现男女配对和共同生育，尚未覆盖收养、单亲、同性伴侣、辅助生殖与不婚生育。
- 家庭内部暂时平均分配教育预算，没有长幼、性别偏好、健康差异或“重点培养某一个孩子”。
- “成功”暂以经济地位达到阈值表示，尚未加入幸福、健康、照护贡献、科研文化成就或风险偏好。
- 国家数据均为缩放后的机制参数，模拟人口不是现实人口数量。

## 九维资本

| 资本 | 当前作用 | 子女增多时 |
|---|---|---|
| 金融资产 | 教育投入、住房、成家启动金 | 接近按人数摊薄 |
| 人力资本 | 学习环境、职业准入 | 中度传递 |
| 社会资本 | 推荐、信息与关系网络 | 较慢摊薄 |
| 政治资本 | 公共权力职业入口 | 传递强，但受制度开放度抑制 |
| 文化资本 | 学习习惯、表达与职业认知 | 中度摊薄 |
| 住房资本 | 成家门槛 | 快速摊薄 |
| 健康资本 | 劳动能力和死亡风险 | 缓慢传递 |
| 照护时间 | 每孩陪伴与教育 | 快速摊薄 |
| 债务 | 消耗现金并抬高风险 | 多孩和高房价可能累积 |

## 职业继承

职业不是固定继承。模型通过四条渠道提高父子/母子职业相似概率：专业知识、人力资本、社会关系和职业准入门槛。制度开放度越高，能力权重越大，关系继承权重越低。高风险不稳定劳动的代际延续同样是概率性的“黏性底层”，不是给家庭或个人贴永久标签。

OECD 的跨国研究认为，父母教育、收入和职业与子代结果存在显著的代际持续性；即使控制子代自身教育，部分国家仍存在父母背景影响。职业相关性可能来自专业知识、教育分层、准入壁垒和家庭网络。因此模型没有把职业同类继承解释为先天决定。

## 动态死线

“死线”只表示在给定制度下稳定成家和生育的资源承载阈值，不表示人的价值。它是软概率曲线：低于阈值后概率快速下降，但不会归零。阈值随住房压力、养育成本和发展水平上升，随福利托底和育儿支持下降。

多代实验必须做阈值敏感性分析。若住房昂贵、福利弱，100资源集中给一人可能比拆给三人更容易延续；若公共教育、住房和托育覆盖较好，多孩的“多次尝试”优势可能重新出现。前者不是预设为普遍规律。

## v4 动态家庭与空间机制

- 经济周期是正弦周期与随机负向冲击的组合；衰退提高失业、债务、离婚和返乡倾向，繁荣提高工资和再就业。
- 离婚会分割现金和住房资本，产生新家庭分支，并按概率决定子女监护；离婚者可进入再婚池。
- 性别差异通过劳动参与、工资差距、母职职业中断和子女投资偏好实现，所有参数都可设为零以运行性别中性反事实。
- 地区具有城市/乡村属性、工资、住房、学校和就业机会；迁移由这些收益和家庭资源脆弱性共同决定。
- 制度开关实验遵守“一次只改变一个制度”的规则，避免把公共教育、住房供给、反裙带和福利托底混成单一政策包。

## 中国政策开关

| 时期 | 模型标签 | 当前实现 |
|---|---|---|
| 1971—1979 | 晚、稀、少 | 目标子女上限 3、执行强度 0.55 |
| 1980—2015 | 独生子女为主（含例外） | 上限 1、执行强度 0.88 |
| 2016—2020 | 全面两孩 | 上限 2、执行强度 0.55 |
| 2021— | 三孩及配套支持 | 上限 3、低限制、托育支持增加 |

执行强度是人为设定的实验参数。真实版本必须按城乡、民族、地区和年代分别校准，不能把全国长期视为完全一致的硬性一孩制度。

## 下一轮最有价值的条件

1. 家庭资源的真实含义：年收入、净资产、可用于教育的现金，还是社会关系资本。
2. “成功”的目标：进入收入前 10%、大学毕业、跨阶层、还是家族总财富增长。
3. 子女结果相关性：同胞共享基因、学校、地区冲击，因此并非完全独立的彩票。
4. 家庭策略：平均分配、优先长子、优先最有潜力者，或观察成绩后动态追加。
5. 国家制度：税收、免费教育、住房、养老金与医疗会改变“多一个孩子”的边际成本。
6. 人口反馈：劳动力短缺推高工资、老龄化提高税负、技术进步替代劳动。
