# 通用人口沙盘与控制变量实验架构 · 2026-10-02

本项目的长期目标是可校准、可复现、可在真实空间中进行控制变量与机制消融的流动人口沙盘。用户提出的一孩/多孩比较是示例课题；平台还应支持住房、教育、照护、迁移、灾害、就业和其他机制的探索。课题不应决定核心引擎的结构。

本阶段先交付完整状态分叉和通用实验运行器，使不同课题可以共享对照设计、配置验证、过程开关、指标与审计。当前机制和四国起点仍主要用于探索；运行成功、分支可复现或审计通过，都不等于真实人口校准完成。

## 1. 平台与课题的分层

| 层 | 责任 | 本阶段状态与后续边界 |
|---|---|---|
| 数据与情景 | 国家/地区ID、初始人口、参数、来源与证据级别 | 复用现有 `FamilyScenario`；真实人口数据包后续接入 |
| 模拟核心 | 人口、家庭、经济、照护、教育、迁移等年度状态演进 | 复用 `FamilyWorld`，添加明确的过程开关 |
| 状态分叉 | 保存世界状态、随机数状态、恢复独立世界 | 同进程完整deepcopy；还不是跨版本持久化协议 |
| 实验规格 | 起点、预热期、干预组、seed、观察期、指标 | 参数干预与机制移除可组合；baseline自动生成 |
| 结果与审计 | 逐年检查、同seed配对差值、多seed汇总、来源hash | 总量和地区人口闭合；外生路径、双边转移与双系谱系可审计 |
| 交互与地图 | 加载实验、查看地图、曲线和假设 | 未来使用同一Python结果契约；本阶段不改成地图或月引擎 |

现有美国住房—生育经验研究继续承担验证任务。新实验运行器使用丰富的 `FamilyWorld`；简版 `World` 适配器的预测成绩不能直接替它提供经验有效性证据。

## 2. 同一起点的完整状态分叉

接口为 `FamilyWorld.checkpoint() -> FamilyCheckpoint`。checkpoint提供 `restore()`、`fingerprint` 和 `year`：

```python
checkpoint = world.checkpoint()
baseline = checkpoint.restore()
intervention = checkpoint.restore()
```

checkpoint保存完整世界副本，包括人口与家庭、关系、国家和地区状态、ID计数器、历史及随机数生成器状态。每次恢复得到独立世界；修改或推进某一分支不能污染原世界、checkpoint或其他分支。`fingerprint` 用于检查分支是否来自同一状态。

每个seed只初始化一次并运行一次预热，再从该状态恢复baseline和所有干预组。`warmup_years=0` 表示初始化后立即分叉；大于0表示先让各组共有的世界演化若干年，再开始干预。观察期由 `years` 指定，预热期不应混入干预后的效果估计。

`snapshot()` 面向展示和汇总，不能代替checkpoint。checkpoint目前用于同一进程内恢复，不保存为可跨机器、Python版本或模型版本继续运行的文件。输出中的起点指纹也不能单独重建世界，复现仍需情景、实验规格、源码与运行环境记录。

## 3. 通用实验接口与干预语义

核心接口：

```python
ExperimentArm(
    name="example",
    country_parameters={},
    region_parameters={},
    disabled_processes=(),
    simulation_parameters={},
)

run_experiment(
    scenario,
    arms,
    years=3,
    seeds=[20261002, 20261003],
    warmup_years=2,
    metrics=("population", "median_household_resources"),
    freeze_exogenous_path=True,
)
```

`arms` 至少列出一个研究者希望比较的干预组；运行器自动添加无干预baseline，`baseline` 是保留名称。组名和seed必须分别唯一，未知国家、地区、字段、过程或指标以及非有限值、布尔型数值和越界参数均被拒绝，不能悄悄忽略。国家、地区和模拟参数均使用显式允许名单，并非所有dataclass字段都能直接干预。用于初始化的人数、身份或结构字段不能伪装成分叉后的即时参数干预；改变初始人口需要另设情景，不能再声称起点完全相同。观察终点不能超过原情景的 `end_year`。

`country_parameters` 按国家ID映射参数，例如 `{"USA": {"housing_pressure": 0.25}}`；`region_parameters` 按国家ID、地区ID映射参数，例如 `{"CHN": {"CHN-east-urban": {"school_supply": 0.85}}}`。`simulation_parameters` 只接受 `adult_pairing_rate`、`international_migration_rate`、`resource_investment_share`、`inheritance_share` 四个0—1比例参数，不允许在分叉后改seed或时钟。

一次调整多个参数是联合干预，要按联合总效应解读。若要区分单项贡献和交互作用，应显式列出单项组及组合组，而不是把组合结果归给某一个参数。`apply_intervention()` 在修改世界前验证完整干预，并返回实际变化字段的前后值；失败的干预不能留下部分修改。已有禁用过程会保留，新列表只追加禁用，不会隐式重新启用原来关闭的过程。

国家和地区是两个明确层级。例如地区在初始化时可能由国家配置生成；分叉后提高国家 `public_education_quality` 不应暗中重建地区、覆盖地区 `education_quality` 或改变居民分布。需要改变地方学校供给时，必须显式指定地区参数。住房压力与地区住房成本、国家照护支持与地区照护供给也应遵循相同原则。

参数干预在分叉时生效，之后按模型原有机制演进。改变住房压力不等于把所有家庭住房开支锁死；提高福利不等于后续收入、迁移和生育都保持不变。这些内生反应正是当前总效应的一部分。

## 4. 七类过程开关

`disabled_processes` 接受下列过程名。开关作用于分支后续步骤，不倒改checkpoint中已经发生的事件。

| 过程 | 关闭后的语义 | 仍可能变化的内容 |
|---|---|---|
| `births` | 不生成新的出生事件 | 起点已有孩子继续年龄增长、受教育和迁移 |
| `deaths` | 不执行新的死亡事件 | 年龄、健康、收入、家庭结构仍可能变化 |
| `internal_migration` | 跳过专门的国内迁移过程 | 婚配引起的同住搬家仍可发生 |
| `international_migration` | 跳过专门的国际迁移过程 | 不能据此推断所有住址或关系均已锁定 |
| `partnership` | 不形成新的伴侣关系 | 已有伴侣继续共同生活，其他未关闭机制仍可改变关系 |
| `divorce` | 不执行新的离婚事件 | 死亡造成的丧偶仍可能发生 |
| `climate_events` | 不抽取新的气候灾害事件 | 起点已有灾害压力继续按原模型恢复；其他经济冲击仍可发生 |

关闭灾害不是立即清除灾害遗留状态，关闭迁移不是锁定住址，关闭死亡也不是健康干预。每个课题要先选择它实际需要的语义。若需要固定每家住址或共享整条灾害路径，必须等待相应控制能力实现，不能用相近开关代替后再作同样解释。

## 5. 结果如何比较

结果先按 `seed × country × year × metric` 对齐，计算每个干预组相对baseline的差值，再跨seed汇总。应始终保留baseline值、干预值和配对差值，不能只给最后一年的总体均值。

多seed汇总报告配对差值的均值、最小值、最大值和样本标准差；只有一个seed时样本标准差为 `null`。这些描述模型随机性与seed间变动，不应标为95%置信区间，也不覆盖参数不确定性、数据测量误差或模型结构错误。不同指标可能支持不同排序；人口增长、生活质量、照护缺口和机会分配不能自动合并为一个“最好”的结论。

本阶段允许说“在这个指定模型、参数和起点分布下，改变X后的模拟结果与baseline相差多少”。它尚不支持直接声称现实政策的因果效应。

尤其要区别两件事：

1. 完整checkpoint保证分叉瞬间状态和随机数状态相同，空干预应与baseline完全复现。
2. 干预开始后，各分支可能消耗不同数量的顺序随机抽样，因此同一居民、年份或机制不一定继续收到相同随机冲击。

`freeze_exogenous_path=True` 时，baseline会按 `过程 × 年份 × 国家 × 地区 × 实体 × draw` 的稳定键记录经济冲击和气候事件，随后各干预组严格回放同一JSON路径。查找顺序、地区排列和家庭主随机流的消耗不再改变这两类冲击；缺失键会直接失败，而不是现场补抽。修改冲击发生率或严重度的干预与冻结路径语义冲突，运行器会拒绝该组合。

这仍不是所有居民事件已经对齐的个体反事实实验。出生、婚配、迁移、就业、死亡等内生事件继续使用顺序随机流；移除机制后可能发生随机抽样错位。元数据的 `event_alignment_scope` 明确记录对齐范围，不能把经济/气候两类外生路径扩写成“全部共同随机数”。

## 6. 审计与复现产物

CLI从 `schema_version: 1` 的实验JSON读取情景位置、观察期、预热年数、seed列表、指标和干预组；`scenario` 路径相对实验JSON所在目录解析：

```bash
python3 scripts/run_controlled_experiment.py experiments/general_controls.json --output outputs/general_controls.json
```

仓库中的 `experiments/general_controls.json` 是可直接检查和修改的多领域示例，不把家庭规模作为固定输入。查看其具体字段后复制为新实验规格；不要为新课题复制一套模拟循环。

`run_experiment()` 保存解析后的设计、整个 `population_simu` 包的Python源码hash、seed、分叉年份和checkpoint指纹，以及每组逐年指标、配对差值和汇总；CLI调用的 `run_spec()` 另外保存实验规格与情景文件的SHA-256。源码hash可以追溯计算实现；它不是现实真实性评分。输出路径应为新artifact，避免覆盖已归档研究结果。

| 结果字段 | 内容与读取规则 |
|---|---|
| `configuration` / `spec` / `source_sha256` | 有效情景与设计、规格和情景文件hash、源码hash |
| `runs` | 每个seed的checkpoint信息、预热审计、baseline与各干预组 |
| `runs[].frozen_exogenous_path` | 启用时保存严格回放的经济和气候事件键值；未启用时为 `null` |
| `runs[].baseline.history` / `runs[].arms[name].history` | 未四舍五入的全部年度统计，以 `country` 和 `year` 标识；不仅限于所选 `metrics` |
| `runs[].baseline/arms[name].transfer_ledger_summary` | 按年份、机制和资源单位汇总的双边转移记录数与金额；完整逐笔账本保留在运行中的 `FamilyWorld` |
| `runs[].arms[name].intervention` | 实际参数变化和禁用过程的前后集合 |
| `paired_differences` | 所选指标的 `baseline`、`value`、`difference`；只包含分叉后的年份 |
| `summary` | 按干预组、国家、年份、指标汇总的 `mean_difference`、`seed_min`、`seed_max`、`sample_sd` |

`history` 包含分叉当年的既有历史行，它反映干预前已发生的结果，不会因为分叉后的参数变化被重算；不能把该行解释成干预已经产生效果。后续 `years` 个年度步骤才进入配对差值。

逐年审计检查基本数值合法性、国家/地区等汇总一致性、在世个人的家庭归属与地理归属、配偶互相引用和父母引用，并验证世界总人口满足 `期末人口 = 期初人口 + 出生 - 死亡`。世界内国家间迁移在总量上抵消。

自2026-10-03起，实验审计还保存逐地区人口流量账本，验证
`期末人口 = 期初人口 + 出生 - 死亡 + 各类迁入 - 各类迁出`。账本分别标识专门国内迁移、国际迁移、婚配搬家、离婚搬家及未分类流量；未分类流量不会被强行归入已有机制。

自2026-10-04起，`FamilyWorld.transfer_ledger` 对现有正式托育费、祖辈照护、子女发展投入、成家转移、离婚资产分割和房产遗产记录显式转出方与转入方。现金使用模型货币单位；非现金资源保留 `resource_kind`，不同种类不能直接相加。该账本观察既有机制，不创造新的转移决策。`FamilyWorld.genealogy(person_id)` 同时沿母亲和父亲指针查询祖先，标出因谱系重合而同时出现于两侧的祖先，并可查询后代；谱系不再依赖姓氏推断。

地区人口账本仍是年度过程阶段聚合，而转移账本目前覆盖上述已接入节点，并非所有收入、消费、税收和政府支出的总账。事件寻址随机数当前也只覆盖经济和气候外生过程，尚不是完整逐事件日志。

本文件记录架构、使用方式与解释边界，不预先填入未执行的运行数字。具体测试数量、实验规模和结果应以阶段运行产物及对应提交记录为准。

## 7. 不同课题共享同一运行器

| 模板 | 可使用的本阶段干预 | 指标与解释重点 |
|---|---|---|
| 住房 | 国家住房压力、显式地区住房成本 | 家庭资源、住房状态、生育与迁移的联合反应 |
| 照护 | 托育容量/补贴、长期照护支持、地方服务供给 | 照护缺口、家庭负担、就业与代际差异 |
| 学校 | 国家教育参数、显式地区学校供给/教育质量 | 既有教育相关指标；收入流动需长期指标与校准 |
| 迁移 | 分别关闭国内或国际迁移过程 | 人口分布、地区资源差异；不能解读为完全禁止搬家 |
| 灾害 | 关闭新气候事件、调整恢复参数 | 资源和压力恢复；历史残余压力仍属于共同起点 |
| 家庭规模 | 后续用专门策略/政策干预协议调用同一运行器 | 实际出生策略与政策上限分开；存续、生活质量与代际流动共同评价 |

表中研究指标是课题设计方向；只有运行器支持的现有指标可直接写入 `metrics`。需要成年存活率、双系后代延续、固定年龄收入转移等新指标时，先补数据和计算契约，不能用资源分数代替。

## 8. 后续建设顺序与验收

| 阶段 | 交付 | 关键验收 |
|---|---|---|
| 当前：通用实验基础 | checkpoint、显式参数干预、七类开关、CLI、配对结果、来源记录 | 分支独立、空干预一致、组顺序不改变结果、错误设计拒绝、逐年审计 |
| 已完成：事件与路径控制（首批） | 稳定事件键、经济/气候外生路径记录与严格回放 | 地区顺序和主随机流消耗不改变事件；各组保存同一路径；范围明确 |
| 已完成：流量与谱系（首批） | 地区人口账本、现有资源/现金双边日志、双系祖先与后代查询 | 人口逐年闭合；转移双方显式；谱系不依赖姓氏 |
| 后续：事件覆盖扩展 | 逐步为必须配对的内生机制设计稳定实体与事件序号 | 每次只扩展一个机制并检查选择效应，不能宣称全局已对齐 |
| 时钟与空间 | 统一日期和步长，地理ID/边界/迁移OD适配层 | 年/月率与现金流转换正确；地区汇总能与地图一致连接 |
| 可校准研究包 | 美国优先，其后中国、印度及按课题选择的重要地区 | 输入证据分级、参数校准、预先确定验证窗、现实指标可比 |

事件寻址随机数应稳定标识原有居民及其事件；新出生或消失的个体不能强行配成现实中不存在的对应者。外生路径冻结要独立于内生经济响应，明确什么是输入、什么是输出。状态锁定则需要说明对守恒、婚配、继承或健康机制的冲突处理。

月引擎与地图通过适配层接入同一实验契约。先转换年龄、事件概率、收入、债务、妊娠、退休和政策日期，再进行步长一致性检验；不能把年度循环每月重复。地图首先使用真实地区聚合与可审计迁移流，不用示意坐标冒充真实居住地点。

每个达到验收条件的阶段单独形成Git提交并推送，使架构演进、测试证据和研究结果可追踪；未实现能力继续明确列在路线图中。
